# spec.md の作成

- 製品仕様を作成すること

# spec.md の更新
- 仕様内容検討後更新のため、明確な更新指示以外では spec.md を更新しないこと

# 更新制限
- spec.mdの検討を行うエージェントは、spec.md専用で作業すること。  
  設計や実装の検討を行うエージェントは、spec.mdを更新しないこと。
